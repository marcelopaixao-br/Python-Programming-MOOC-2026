## 🎯 Sobre a Seção

Esta primeira parte introduz os fundamentos essenciais da programação em Python. O foco é compreender como estruturar comandos básicos, exibir informações na tela, realizar cálculos matemáticos, trabalhar com textos e números e documentar o código adequadamente.

---

## 💡 Conceitos Principais

### 1. A função `print()`

Utilizada para exibir textos e resultados na tela.

```python
print("Hi there!")
```

### 2. Execução sequencial de comandos

O Python executa as instruções na ordem em que aparecem no programa.

### 3. Operações aritméticas

Utilização de operadores matemáticos para realizar cálculos.

| Operador | Operação |
|---|---|
| `+` | Adição |
| `-` | Subtração |
| `*` | Multiplicação |
| `/` | Divisão |

Exemplo:

```python
print(365 * 24 * 60)
```

### 4. Strings e números

Strings representam textos e são delimitadas por aspas. Números podem ser utilizados diretamente em operações matemáticas.

```python
print("365 * 24 * 60")
print(365 * 24 * 60)
```

O primeiro comando exibe uma expressão como texto; o segundo realiza a multiplicação e exibe seu resultado.

### 5. Comentários no código

O símbolo `#` permite inserir comentários que ajudam a documentar o programa. Eles não são executados pelo Python.

```python
# This is a comment
print("Hello there!")
```

### 6. Quebras de linha

A sequência de escape `\n` permite inserir uma quebra de linha dentro de uma string.

```python
print("First line\nSecond line")
```

### 7. Aspas simples e duplas

Python permite delimitar strings utilizando aspas simples (`'`) ou duplas (`"`).

A combinação das duas permite incluir aspas dentro de um texto sem confundir o interpretador.

```python
print('print("Hello there!")')
```

Nesse exemplo, as aspas simples delimitam a string externa, enquanto as aspas duplas fazem parte do texto exibido.
