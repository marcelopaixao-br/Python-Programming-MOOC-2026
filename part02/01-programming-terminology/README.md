# Part 2: Programming Terminology

This folder contains exercises from **Part 2 - Section 1: Programming Terminology** of the [Python Programming MOOC 2026](https://programming-26.mooc.fi/) course offered by the University of Helsinki.

## 📂 Exercises Included

| Exercise | Description | Key Concepts |
| :--- | :--- | :--- |
| **Fix the Syntax** | Correcting syntax, indentation, and conditional logic errors in a basic Python script. | `if` statements, compound assignments (`-=`), debugging |
| **Number of Characters** | Evaluating string length and using conditional branches to display custom output. | Built-in `len()` function, string evaluation |
| **Typecasting** | Converting floating-point numbers to integers and separating decimal components. | `float()`, `int()`, floor functions, math operations |

---

## 🚀 Key Learnings & Concepts

* **Statements & Blocks:** Understanding how instructions are structured and grouped via code indentation.
* **Expressions & Data Types:** Working with evaluated expressions (`int`, `str`, `float`, `bool`) and inspecting types using `type()`.
* **Type Conversion (Typecasting):** Explicitly changing data types to handle numeric data accurately.
* **Debugging Basics:** Utilizing trial outputs and print statements to trace execution flow and isolate logic bugs.
