## Part 2: More Conditionals

This section focuses on expanding control flow by utilizing multi-way branching with `elif` statements, handling mutually exclusive conditions with `else`, and applying relational operators to both numbers and strings.

### 📂 Exercises Included

| Exercise | File Name | Description | Key Concepts |
| :--- | :--- | :--- | :--- |
| **Age of maturity** | `01_ex_Age_of_maturity.py` | Evaluates if a user's entered age meets the legal maturity threshold (18). | `if`/`else` statements, relational operators (`>=`) |
| **Greater than or equal to** | `02_ex_Greater_than_or_equal_to.py` | Compares two integer inputs to determine which is greater or if they are equal. | Multi-way branching (`if`, `elif`, `else`), numeric comparison |
| **The elder** | `03_ex_The_elder.py` | Collects name and age data for two individuals to determine who is older or check for ties. | Multi-variable input, dynamic string formatting (`f-strings`) |
| **Alphabetically last** | `04_ex_Alphabetically_last.py` | Compares two string inputs to determine alphabetical ordering or identify duplicate inputs. | String comparison operators (`<`, `>`), text validation |

---

### 🚀 Key Learnings & Concepts

* **Alternative Branches (`elif`):** Executing alternative blocks of code only when preceding conditions evaluate to `false`.
* **Exhaustive Control Flow (`else`):** Catching all remaining scenarios where previous conditional checks fail.
* **String Comparison:** Evaluating alphabetical sorting order using standard relational operators (`<` and `>`).
